# پورتفولیو سپنتا

## اجرا روی کامپیوتر
    npm install
    npm run dev      # http://localhost:3000

## انتشار (Deploy)
- Vercel: پوشه را در GitHub بگذارید و Import کنید (یا `npx vercel`)
- سایت استاتیک (Netlify و ...): فقط فایل `index.html` را آپلود کنید

## ویرایش
- همه‌ی طراحی در `public/portfolio.html` است
- شماره‌ی واتساپ: در همان فایل دنبال `989130772988` بگردید
- لینک‌های Dribbble و Behance را جایگزین `href="#"` کنید
